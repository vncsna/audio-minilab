## audio-minilab

A personal 1:1 course on the Arturia MiniLab 3 and music production, taught by an AI agent.

**Goal:** compose, mix, and export one original track (~3 min), on my own, using the MiniLab 3 and REAPER on Linux.

**Stack:** Arch Linux · PipeWire · REAPER · Arturia MiniLab 3 · native VSTi (no MIDI Control Center / Analog Lab — no native Linux build)

## Files

| File | Purpose |
|---|---|
| `AGENTS.md` | Course rules: environment, teaching method, pacing, file conventions |
| `course/GUIDE.md` | Roadmap, current progress, session log, student notes |
| `course/GLOSSARY.md` | Translated terms (English ↔ Portuguese) |
| `configs/` | REAPER and MiniLab 3 settings that live outside the repo (keymap + manual steps) |

## Progress

`8 / 18` lessons — a drum groove recorded with the pads. Next: **3.2 — Grid, quantization, and humanization**.

## How it works

- One lesson per session.
- Every lesson has one concept, one exercise, and an explicit completion criterion.
- `GUIDE.md` is updated at the end of every session and is the single source of truth for progress.

**To resume:** read the *Current state* block in `course/GUIDE.md` → find the next lesson in the roadmap → do only that one.
